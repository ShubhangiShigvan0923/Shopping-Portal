# Online Shopping Portal

## Project Description
An Online Shopping Portal developed using PHP and MySQL that allows users to browse products, register, login, add items to cart, and place orders.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- XAMPP

## Features
- User Registration & Login
- Product Categories
- Product Search
- Shopping Cart
- Order Management
- Admin Panel

## How to Run
1. Install XAMPP
2. Copy project into htdocs
3. Import SQL file into phpMyAdmin
4. Start Apache and MySQL
5. Open localhost/shopping
